# AI Library — Release Checklist

Публичный сайт: https://maikllx.github.io/AI-Library/

## Автоматизированные проверки

- [x] Встроенный JavaScript проходит проверку синтаксиса.
- [x] Нет повторяющихся статических HTML ID.
- [x] Все локальные ресурсы, манифест и значок существуют.
- [x] Проверены метаданные приложения и офлайн-навигация.
- [x] Проверены наличие резервного копирования/восстановления и безопасная обработка ID книг в каталоге.
- [x] Перед публикацией GitHub Pages запускает релизный валидатор.
- [x] Генерация ИИ имеет ограничение ожидания и корректное восстановление состояния интерфейса.
- [x] Версия кеша service worker обновлена для новой оболочки.

## Ручные проверки перед объявлением стабильного релиза

### Сайт и чтение
- [ ] Android Chrome: каталог, поиск, жанры, избранное, открытие книги и возврат в каталог.
- [ ] Проверить размер шрифта 14/24 px и все три межстрочных интервала: текст не выходит за пределы страницы.
- [ ] Перелистывание кнопками, клавиатурой и жестами; переход между главами.
- [ ] Перезагрузка страницы и продолжение чтения с сохранённой страницы.
- [ ] Экспорт резервной копии, импорт в чистом профиле и проверка личных книг, избранного и прогресса.
- [ ] Открыть сайт онлайн, затем проверить запуск оболочки офлайн; убедиться, что генерация и обновление общей библиотеки корректно объясняют отсутствие сети.

### Генерация ИИ
- [ ] Успешно создать главу и сохранить личную книгу.
- [ ] Проверить ошибку API/отсутствие сети: интерфейс должен восстановиться и разрешить повторную попытку.
- [ ] Проверить длительный запрос: через 90 секунд он должен завершиться понятным сообщением, без зависшей кнопки.

### Cloudflare Worker и общая библиотека
- [ ] Проверить `/health` и корректность CORS с домена GitHub Pages.
- [ ] Проверить `/books`: API должен возвращать корректный массив книг, а не только пустой список, если общая библиотека должна быть наполнена.
- [ ] Открыть общую книгу и убедиться, что главы загружаются из D1.
- [ ] Проверить запуск Cron `0 9 * * *` в журнале Cloudflare и подтвердить, что ежедневная публикация действительно создаёт запись в D1.
- [ ] Убедиться, что секрет провайдера ИИ хранится только в Cloudflare Secrets и никогда не попадает в клиентский код.

## Важно

Автоматические проверки GitHub Actions проходят, но они не могут подтвердить поведение браузера на физическом устройстве или доступность Cloudflare Worker/D1. Считать релиз полностью проверенным можно после выполнения ручных пунктов выше.
