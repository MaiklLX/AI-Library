# Публикация книг в AI Library

Книги из репозитория автоматически добавляются в публичный каталог сайта через `content/catalog.json`. Для публикации новой книги достаточно добавить отдельный JSON-файл в эту папку и зарегистрировать его в каталоге. Редактировать `index.html` для каждой книги не нужно.

## Формат книги

Файл: `content/books/<slug>.json`. Идентификатор — уникальный латинский slug из строчных букв, цифр и дефисов; он должен совпадать с `id` в записи каталога.

```json
{
  "id": "the-last-archive",
  "title": "Последний архив",
  "author": "AI Library",
  "genre": "Фантастика",
  "description": "Краткая аннотация книги.",
  "tag": "НОВАЯ КНИГА",
  "cls": "fantasy",
  "symbol": "✦",
  "length": 8,
  "chapters": [
    {
      "title": "Глава 1. Начало",
      "content": "Полный текст главы..."
    },
    {
      "title": "Глава 2. След",
      "content": "Продолжение истории..."
    }
  ]
}
```

Поддерживаются также главы в виде обычных строк. Допустимые классы обложки: `fantasy`, `detective`, `romance`, `horror`, `adventure`. Если поле необязательно, сайт подставит безопасное значение по умолчанию.

## Регистрация в каталоге

Добавьте в `content/catalog.json` запись в массив `books`:

```json
{
  "version": 1,
  "books": [
    {
      "id": "the-last-archive",
      "path": "./content/books/the-last-archive.json"
    }
  ]
}
```

После коммита GitHub Actions проверит формат каталога, уникальность ID, наличие файлов книг и обязательные поля. После успешной публикации GitHub Pages книга появится в общем каталоге. Обновление может потребовать перезагрузки сайта, если браузер держит старую оболочку.

## Процесс с ChatGPT

1. В чате согласуем тему, жанр, стиль, объём и структуру.
2. Я подготовлю текст книги и упакую его в JSON-файл.
3. По твоему явному запросу добавлю файл и запись каталога в репозиторий.
4. GitHub Actions проверит данные и опубликует сайт.

Публикация происходит только по явному запросу. Личные книги, сохранённые в браузере, не становятся публичными автоматически.
