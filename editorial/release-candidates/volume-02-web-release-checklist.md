## Расписание и автоматический доступ

- Утверждённое время тома II: `2026-11-09T18:00:00+03:00` — 9 ноября 2026 года, 18:00 МСК.
- В каталоге-кандидате том зарегистрирован как `scheduled`, `metadataOnly: true`, `chapterCount: 18`, с тем же `releaseAt`.
- До времени релиза единый reader guard блокирует открытие, поиск по каталогу и случайную рекомендацию; прямой URL также не открывает книгу.
- После наступления `releaseAt` guard снимается автоматически, но только если в каталоге есть согласованная запись с полным числом глав и корректным путём к JSON-тексту. Текст загружается по обычному пути книги, карточка серии меняет состояние на «Опубликован» и предлагает «Читать том».
- Открытая страница каталога проверяет смену состояния каждую секунду; при прямом переходе до даты снимается заставка запуска читателя, поэтому экран не остаётся пустым.
- Метаданные каталога учитывают `releaseAt`, чтобы изменение расписания не терялось в локальном сравнении.

## Ограничения перед production

- Изменения находятся только в редакторской ветке; `main`, GitHub Pages и рабочий каталог production не изменялись.
- Это статическая проверка кода, не реальный браузерный тест. Мобильная/десктопная вёрстка, клики и фактический запуск GitHub Actions ещё требуют проверки.
- Важно: клиентский guard управляет доступом через интерфейс. Если JSON книги будет включён в публичный Pages deployment заранее, технически его можно будет запросить напрямую по известному URL. Для строгой недоступности самого файла до релиза нужен серверный шлюз/Worker либо выкладка тела книги только в момент релиза. До решения этого вопроса не считать клиентскую блокировку криптографической или серверной защитой.
- Том I пока не имеет отдельного JSON полного текста в AI Library. Его редакторский макет в рукописном репозитории помечен как не утверждённый автором к публикации. Таймер не должен открывать пустую/неподготовленную книгу; сначала необходим отдельный release-ready файл и авторское утверждение.
- Тома III–VI остаются запланированными; общий механизм использует `releaseAt` каждого тома, но не включает кнопку чтения без согласованной записи каталога и полного тела книги.

PDF и EPUB не входят в эту сборку.
