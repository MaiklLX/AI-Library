# Том II — статическая проверка автоматического релиза

Дата: 1 ноября 2026 года  
Ветка: `editorial/volume-02-web-release-candidate`

## Проверено

- Каталог и манифест серии используют одно время: `2026-11-09T18:00:00+03:00`.
- Том II присутствует в каталоге со статусом `scheduled`, без встроенного текста, с 18 главами и правильной ревизией.
- Функция `isBookReleaseLocked` блокирует том до даты/времени релиза.
- Блокировка применяется при открытии книги, внутри читателя, в каталожной выдаче, в жанровых фильтрах и случайной рекомендации.
- Прямой URL до даты не открывает текст; временная заставка снимается, чтобы читатель не оставался на пустом экране.
- Открытая страница каталога обновляет доступ при наступлении времени.
- Страница серии после плановой даты меняет карточку тома на «Опубликован» и включает ссылку чтения.
- Сервис-воркер запрашивает каталог, манифест серии и JSON книги по сети с обновлением кеша.
- 10 из 10 независимых статических проверок прошли.
- Синтаксическая компиляция: 9/9 встроенных скриптов `index.html`, 2/2 скрипта `series.html`.

## Не подтверждено

- Реальный запуск `scripts/validate.mjs` в GitHub Actions на этой ветке.
- Браузерный тест на телефоне и десктопе.
- Фактическое открытие текста на границе времени в живом браузере.
- Серверная защита URL файла книги до релиза: текущий guard клиентский. Если JSON будет размещён в публичном Pages deployment заранее, прямой запрос к файлу может обойти интерфейс. Для строгой защиты потребуется серверный шлюз/Worker или выкладка самого файла только в момент релиза.

## Важная зависимость серии

Том I ещё не собран в AI Library как отдельный полный JSON. Найденный в рукописном репозитории макет содержит 16 глав, но аудит прямо помечает его как не утверждённый автором публикационный файл. Его нельзя автоматически открывать только по достижении даты, пока не подготовлен и не утверждён release-ready текст.

Тома III–VI имеют даты в манифесте, но их тела книг ещё предстоит подготовить. Механизм времени общий; готовность содержимого проверяется отдельно.
