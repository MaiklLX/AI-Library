## Автоматический доступ

- Центральная функция `isBookReleaseLocked` блокирует книги со статусом `scheduled` до точного `releaseAt`.
- Guard используется в каталоге, жанровых фильтрах, «Случайной книге», «Моей библиотеке», продолжении чтения, прямом URL и внутри самого читателя.
- Открытая страница каталога проверяет изменение состояния каждую секунду.
- Страница серии получает каталог и включает кнопку чтения только при наличии metadata-only записи с полным числом глав, корректным путём, статусом и тем же `releaseAt`.
- По достижении даты карточка меняется на «Опубликован» и предлагает «Читать том».
- Service Worker использует network-first для каталога, манифеста серии и файлов книг; версия кэша поднята до v72.
- Валидатор проверяет все шесть дат и точную границу времени.

## Статическая приёмка

20/20 проверок пройдены:
- целостность текстов I–II и соответствие каталога;
- точное совпадение шести дат;
- отсутствие читательских записей III–VI до готовности файлов;
- блокировка прямых ссылок и внутренних переходов;
- готовность карточки серии;
- network-first Service Worker и cache v72;
- синтаксическая компиляция 10/10 встроенных скриптов `index.html`, 2/2 скриптов `series.html`, Service Worker;
- 18 граничных проверок: шесть релизов × (за секунду до / ровно в момент / через секунду после).

## Не выполнено

- Реальный браузерный тест на телефоне и десктопе.
- Запуск GitHub Actions / `scripts/validate.mjs` на этой ветке.
- Серверная защита самого JSON до релиза. В статическом GitHub Pages интерфейсный guard не мешает запросить заранее выложенный JSON по известному URL. Для строгого ограничения нужен Worker/шлюз либо выкладка тела книги только в момент релиза.
- Интеграция SVG-скетчей в страницы текущего текстового ридера. В веб-тексте тома I оставлена подпись скетча без сырой Markdown-ссылки.
