## Автоматический доступ

- Общий `isBookReleaseLocked` блокирует scheduled-книги до точного `releaseAt`.
- Проверки доступа установлены в списках/жанрах, случайной книге, «Моей библиотеке», продолжении чтения, прямой ссылке и самом окне читателя.
- Уже открытый каталог перепроверяет состояние каждую секунду.
- Страница серии сверяет ID, metadata-only entry, число глав, путь и одинаковый `releaseAt`; при наступлении даты обновляет карточку и включает ссылку чтения.
- Service Worker — network-first для каталога, манифеста серии и JSON книг; версия кэша v72.

## Что ещё требуется до production

- Реальный браузерный прогон на телефоне и десктопе ещё не выполнен.
- GitHub Pages отдаёт заранее размещённый JSON по прямому URL; клиентский guard управляет доступом через интерфейс, но не скрывает тело книги от технически подготовленного прямого запроса. Для строгой конфиденциальности до даты нужен серверный Worker/шлюз или выкладка тела книги только в момент релиза.
- До браузерной приёмки и отдельного решения по прямому доступу PR остаётся Draft.
