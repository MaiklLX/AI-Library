# «Пока нас не найдут» — рабочее пространство романа

Отдельный редакционный раздел AI-Library для разработки дилогии. Здесь хранятся Story Bible, согласованные сюжетные решения, открытые вопросы и контрольные точки.

> Репозиторий AI-Library публичный. Все материалы этой папки доступны всем. По решению автора архитектура романа хранится здесь; исходные рукописи в этот перенос не включены.

## Документы
- STORY_BIBLE.md — канон, персонажи, тайна «Аурелии», романтическая линия и художественная миссия.
- CHECKPOINTS.md — журнал решений и контрольные фразы для новых чатов.
- OPEN_QUESTIONS.md — вопросы, которые ещё нужно разработать.
- KT-044-APPROVED-SEQUENCE.md — утверждённая драматургическая последовательность прошлого Дамиана и Милены.
- KT-044-BETRAYAL-MECHANISM-DRAFT.md — рабочие модели механизма предательства и доказательной цепочки.
- KT-045-MIRA-DAMIAN-CORE-ARC-DRAFT.md — черновик центральной дуги главной пары.

## Правила работы
1. Не писать главы, пока полная архитектура обеих книг не согласована.
2. Разделять закреплённый канон, рабочие предложения и открытые вопросы.
3. Не менять согласованные факты без явного решения автора.
4. Одна глава — один POV; основные POV — Мира и Дамиан.
5. После каждого содержательного этапа обновлять CHECKPOINTS.md, создавать Git-коммит и выдавать ссылку на него и контрольную фразу.
6. Не смешивать этот роман с «Ты в моих планах».
7. Романтика и химия главных героев равноправны детективной интриге; Мира остаётся эмоциональным центром истории.

Последняя утверждённая точка: КТ-044 — направление раскрытия прошлого и предательства. Подробная последовательность находится в KT-044-APPROVED-SEQUENCE.md.
