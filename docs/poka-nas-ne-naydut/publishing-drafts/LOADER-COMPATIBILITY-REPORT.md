# Проверка совместимости дилогии «Пока нас не найдут» с загрузчиком AI Library

**Дата:** 2026-11-08  
**Ветка:** editorial/restore-literary-standard-i16-onward  
**Статус:** аудит завершён; публичная интеграция не выполнялась.

## 1. Формат опубликованной книги

Проверены `index.html`, `scripts/validate.mjs`, `content/catalog.json`, `src/platform/library-store.js`, `book.html`, `series.html` и существующие тома «Ты в моих планах».

Подтверждённый контракт каталога версии 1:

- каждая запись имеет уникальный slug `id`;
- `path` строго равен `./content/books/<id>.json`;
- в каталоге обязательно `metadataOnly: true`;
- `chapterCount` — целое неотрицательное число;
- если статус не `prerelease`, обязательна непустая `revision`;
- JSON тома должен иметь тот же `id`, что и запись каталога;
- для доступной книги требуется непустой массив `chapters`; элементы могут быть строками либо объектами с текстовым полем `content`;
- для каждого тома `revision` в каталоге и JSON должен совпадать.

Загрузчик сначала читает только метаданные из каталога. Полный JSON тома запрашивается только после явного нажатия «Читать» или скачивания. Объект главы вида `{title, content}` поддерживается: заголовок добавляется перед телом главы при открытии читалки. Текущая структура двух черновиков совместима с этим форматом.

## 2. Важное различие статусов

`prerelease` в действующем коде означает закрытый доступ: нормализатор очищает главы, а валидатор требует, чтобы JSON пререлизной книги не содержал доступного текста. Поэтому нельзя просто перенести текущие полные черновики в `content/books/` и поставить им `prerelease`.

Для будущего отложенного выпуска приложение использует `scheduled` вместе с `releaseAt`: чтение блокируется до наступления даты, после чего доступ открывается. Для немедленного релиза используется `published`. Статус `draft` не является предусмотренным публичным состоянием и не должен попадать в `content/catalog.json`.

**Решение на этом этапе:** оба полных JSON остаются в `docs/poka-nas-ne-naydut/publishing-drafts/`; не добавлять их в публичный каталог и не назначать дату релиза.

## 3. Связь томов с дилогией

В проекте пока нет универсальной страницы серии:

- `series.html` жёстко загружает `content/series/ty-v-moih-planah.json` и ожидает шесть томов;
- функция `isSeriesVolumeBook()` в `index.html` распознаёт только ID `published-ty-v-moih-planah-tom-NN`;
- карточка дилогии «Пока нас не найдут» уже существует отдельно и ведёт на `premiere.html?book=poka-nas-ne-naydut`;
- если просто добавить два новых тома в каталог, текущая логика не спрячет их как элементы серии: они могут появиться самостоятельными карточками.

Существующие тома «Ты в моих планах» используют поля `seriesId` и `seriesVolume` в полном JSON. Это подходящий образец для будущей связи, но одного поля недостаточно: главная страница должна распознавать серию универсально, а страница дилогии должна отображать оба тома и проверять доступность каждого по каталогу.

## 4. Безопасная архитектура следующего этапа

1. Подготовить отдельный манифест дилогии в `content/series/` по аналогии с существующим series JSON, но пока хранить его в документационной зоне черновиков.
2. Сделать отдельную страницу дилогии либо аккуратно обобщить существующую страницу серии, не ломая шеститомную серию.
3. Перевести распознавание томов на явную связь `seriesId`/идентификатор серии, сохранив текущую работу «Ты в моих планах».
4. Для каждого тома показывать название, обложку, диапазон/состав глав и статус; не показывать кнопку чтения, пока запись каталога не подтверждает доступ.
5. Перед включением текста в `content/books/` определить окончательные названия томов, индивидуальные обложки, аннотации, revision и политику релиза.
6. Добавить проверки в `scripts/validate.mjs`: соответствие серии, номера томов, числа глав, chapterCount, wordCount и уникальность ID.
7. Только после отдельного авторского решения подключать два тома к каталогу. Никаких изменений `main` без разрешения.

## 5. Результат аудита

- Схема `chapters[].title/content` совместима с читалкой.
- Две черновые сборки содержат 41 и 43 элемента, пустых глав нет.
- Публичный каталог не менялся.
- `content/books/poka-nas-ne-naydut.json` остаётся метаданными закрытой премьеры.
- `series.html` нельзя использовать для дилогии без отдельной адаптации.
- Главный технический риск выявлен заранее: добавление томов в каталог без обновления `isSeriesVolumeBook()` выведет их как отдельные карточки.
- Не назначены `releaseAt`, `revision` и публичный статус; не создавались записи томов в `content/books/`.
