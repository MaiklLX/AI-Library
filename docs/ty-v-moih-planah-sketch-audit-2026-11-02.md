## Решение для текущего релиза

Текущая читалка формирует страницы из обычного текста, измеряет и разбивает текст на страницы, затем выводит страницы через `textContent`. Она не поддерживает встроенные иллюстрации в тексте. Простая вставка Markdown/HTML-ссылки на SVG не отобразит картинку надёжно и может повлиять на пагинацию.

Поэтому в рамках безопасной корректировки удалена только служебная строка скетча № 01 из опубликованного JSON тома I. Сам SVG и редакторская карта в исходном репозитории сохранены без изменений.
