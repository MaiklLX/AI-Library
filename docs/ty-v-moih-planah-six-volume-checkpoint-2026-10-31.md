## 4. Прогресс чтения и доступ

В существующей читалке прогресс хранится по ключу ID книги в `ai-library-progress`. Нормализация публичной книги добавляет префикс `published-` к ID; это сохраняет раздельные записи прогресса для шести уникальных ID томов. Новая страница серии читает эти записи только для отображения индикатора сохранённого прогресса.

Важная зависимость: экран завершения тома активируется только после того, как JSON соответствующей опубликованной книги получит поля `seriesId` и `seriesVolume`. Ни один текст тома не был добавлен в публичный каталог; ни один том не получил статус `published`. Пока эти метаданные не добавлены в утверждённые релизные JSON, существующие книги продолжают работать по старому сценарию.
