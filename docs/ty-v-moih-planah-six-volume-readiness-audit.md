## 3. Важные ограничения готовности

1. Сюжетный аудит не равен литературной вычитке: для томов III–VI в отчётах есть рекомендации по стилистической полировке, повторяющимся формулировкам и плотности документальных реквизитов.
2. Наличие мастер-текста не означает наличие чистовой издательской копии.
3. Не найдено релизных макетов III–VI. Их необходимо собрать после редакторского прохода и сверки глав.
4. Том II нельзя объявлять готовым: его предпросмотр собран из канонического текста без редакторской правки.
5. Необходимо проверить стыки между всеми шестью томами в едином чтении, в том числе повторяющиеся термины, имена, номера документов и эмоциональный ритм.
6. Необходимо проверить отображение уже существующего скетча тома I в реальной веб-читалке; локальный SVG-рендер не является тестом читалки.
7. Авторское утверждение текста, обложек и издательских материалов ещё не выполнено.

## 4. Рекомендованный порядок работ

### Приоритет A — выпуск I
- Повторно сверить чистовую редакторскую сборку и релизный макет.
- Подготовить web-версию глав для существующего формата читалки.
- Проверить заголовки глав, оглавление, скетч, адаптивную ширину, навигацию и сохранение прогресса.
- Оставить доступ закрытым до отдельного разрешения.

### Приоритет B — выпуски II–VI
- Том II: провести литературный проход по главам 17–34; не использовать текущий тестовый макет как чистовую основу без сверки.
- Том III: литературная полировка глав 35–56 с учётом замечаний аудита.
- Том IV: литературная полировка глав 57–66 с учётом замечаний аудита.
- Том V: литературная полировка глав 67–80 с учётом замечаний аудита.
- Том VI: литературная полировка глав 81–93; сохранить отдельное оформление эпилога.
- Для каждого тома создать отдельный релизный макет, проверить соответствие оглавления и текста, затем собрать данные для web-читалки.

### Приоритет C — сайт
- Создать отдельный манифест серии и отдельные метаданные томов в проектном/черновом слое.
- Только после подтверждения структуры добавить поддержку серии в интерфейс.
- Для закрытых томов показывать статус без ссылки на чтение; для опубликованного — реальную ссылку на книгу.
- Прогресс чтения хранить отдельно для каждого тома.
- Переход после финальной главы томов I–V вести на страницу серии и следующий том; если он закрыт, показывать статус без попытки открыть текст.
- Не менять текущий ID премьеры `ty-v-moih-planah` до завершения безопасной миграционной схемы.

## 6. Контрольный вывод

Серия имеет полный канонический источник и завершённую сюжетную карту шести частей. На уровне издательских сборок подтверждён существенно более высокий уровень готовности тома I; том II пока имеет только тестовый макет без редакторской правки; тома III–VI нуждаются в литературной полировке и создании релизных макетов. Сайт пока получил только техническую спецификацию серии, а не новую публичную структуру.

Следующая контрольная точка должна фиксировать не количество файлов, а фактическую готовность каждого тома по цепочке: редактура → сверка → релизный макет → web-данные → тест читалки.
