# AI Library — библиотека новых миров

Публичный сайт: **https://maikllx.github.io/AI-Library/**

AI Library — адаптивная цифровая библиотека с тёмным интерфейсом и золотыми акцентами. Проект объединяет каталог историй, книжный режим чтения и генерацию личных историй с помощью ИИ.

## Возможности

- Каталог демонстрационных историй, поиск по названию, описанию и жанру.
- Фильтрация по жанрам, избранное и сортировка по названию, длительности и прогрессу.
- Книжный режим: постраничное чтение, анимация перелистывания, бумажная текстура и настройки шрифта/межстрочного интервала.
- Сохранение текущей страницы, части книги и настроек чтения в браузере.
- Экспорт и восстановление личных книг, избранного, прогресса и настроек в JSON.
- Офлайн-оболочка приложения после первого успешного открытия; сохранённые личные книги доступны без сети.
- Кнопка продолжения чтения и визуальный индикатор прогресса.
- Создание личной истории через ИИ и сохранение её в библиотеке текущего браузера.
- Загрузка общей библиотеки через Cloudflare Worker; при ошибке загрузки используется локальный кеш.
- Адаптация под телефоны и компьютеры, клавиатурная навигация и поддержка системного режима уменьшения движения.
- Метаданные для поисковых систем и предпросмотра ссылок, значок и Web App Manifest.

## Архитектура

- `index.html` — интерфейс, каталог и логика чтения.
- `manifest.webmanifest` и `icon.svg` — метаданные веб-приложения и значок.
- `sw.js` — кеширование оболочки для офлайн-открытия.
- `scripts/validate.mjs` — локальная проверка релизных требований.
- Cloudflare Worker — API генерации и общей библиотеки.
- Cloudflare D1 — хранилище общих книг и глав.

Личные книги, избранное, настройки и прогресс хранятся в `localStorage` конкретного браузера. Они не синхронизируются между устройствами и не публикуются в общей библиотеке автоматически.

## Публикация книг из репозитория

Каталог публичных книг хранится в `content/catalog.json`, а полный текст каждой книги — в отдельном JSON-файле внутри `content/books/`. Сайт загружает этот каталог автоматически и объединяет опубликованные книги с демонстрационными, общими и личными книгами. Чтение, поиск, фильтры и прогресс работают в существующем книжном интерфейсе.

Чтобы добавить книгу, создай `content/books/<slug>.json` по схеме из [инструкции по формату](./content/books/README.md), затем добавь в `content/catalog.json` запись с тем же `id` и путём `./content/books/<slug>.json`. Не используй уже занятый ID. GitHub Actions проверяет структуру и файлы до публикации.

## Генерация ИИ

Интерфейс обращается к Worker по адресу:

`https://ai-library-generator.bymaikl.workers.dev/generate`

Для работы генерации Worker должен быть развёрнут, иметь действующий секрет провайдера ИИ и корректно отвечать на запросы с домена GitHub Pages. Секреты нельзя помещать в клиентский код или коммитить в репозиторий.

Текущая пользовательская функция создаёт первую главу/фрагмент, а не гарантированно законченный полноценный роман. Общая библиотека зависит от работоспособности Worker и базы D1; публикацию по расписанию следует проверять отдельно в Cloudflare.

## Проверки релиза

Каждое изменение в `main` автоматически проходит проверку HTML-встроенного JavaScript, уникальности ID, наличия локальных ресурсов, манифеста, сервис-воркера, резервного копирования и безопасной вставки ID книг в каталог. Публикация GitHub Pages запускает ту же проверку до загрузки сайта — при ошибке выкладка не продолжается.

Подробный список автоматических и ручных проверок находится в [RELEASE_CHECKLIST.md](./RELEASE_CHECKLIST.md). Автоматические проверки не заменяют реальное тестирование в браузерах и проверку Cloudflare Worker/D1.

## Публикация

1. Репозиторий: `MaiklLX/AI-Library`, ветка `main`.
2. В настройках репозитория откройте **Settings → Pages** и убедитесь, что публикация настроена для GitHub Pages.
3. После обновления `main` дождитесь завершения workflow публикации, если он настроен.
4. Проверьте сайт: https://maikllx.github.io/AI-Library/

## Резервная копия

В нижней части сайта доступны кнопки **«Резервная копия»** и **«Восстановить данные»**. JSON-файл содержит личные книги, избранное, прогресс чтения и настройки. При восстановлении данные объединяются по идентификаторам книг; публичный каталог и общие книги не изменяются. Храните файл резервной копии в безопасном месте: он может содержать ваши личные тексты.

## Офлайн-режим

После первого успешного открытия сервис-воркер кеширует оболочку сайта. Личные книги, сохранённые в браузере, остаются доступны без сети; загрузка новых общих книг и генерация ИИ требуют подключения к интернету. Браузер может удалить кеш при нехватке места.

## Перед крупным релизом

- Проверить реальное поведение сайта на Android, iOS и десктопных браузерах.
- Проверить генерацию при медленном соединении, ошибке API и повторной отправке.
- Убедиться, что Worker и D1 стабильно возвращают общие книги и главы.
- Пройти сценарии: поиск, фильтры, избранное, чтение, изменение шрифта, перезагрузка и продолжение с сохранённого места.
- При необходимости добавить резервное копирование личных книг и синхронизацию между устройствами.

## Безопасность и приватность

Не храните ключи API в `index.html`. Пользовательские данные в текущей версии остаются в локальном хранилище браузера; очистка данных сайта может удалить личные книги и прогресс. Не загружайте в генератор чувствительную информацию.
