# AI Library

Первый интерактивный прототип виртуальной библиотеки с тёмным премиальным оформлением.

## Возможности
- Адаптивный интерфейс для телефона и компьютера
- Каталог демонстрационных историй и фильтр по жанрам
- Поиск и сортировка
- Чтение демо-фрагментов в модальном окне
- Избранное, сохраняемое в браузере

## Публикация на GitHub Pages
1. Загрузите `index.html`, папку `.github/workflows/` и этот README в корень репозитория `MaiklLX/AI-Library`.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Source: **GitHub Actions**.
4. Откройте вкладку Actions и дождитесь завершения workflow Deploy AI Library to GitHub Pages.
5. Сайт будет доступен по адресу `https://maikllx.github.io/AI-Library/`.

Это фронтенд-прототип: серверной части, ИИ-генерации и автоматической еженедельной публикации пока нет.
